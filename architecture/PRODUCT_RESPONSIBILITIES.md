# Product Responsibility Boundary

- aDoctor never edits or dispatches directly to another specialist.
- aWriter never creates a separate new-article identity unless SIMS Manager issues a aCreator path.
- aCreator never silently edits existing articles; it returns follow-up referrals.
- aMerge never directly deletes, redirects, noindexes, or publishes.
- SIMS Manager does not replace specialist SEO/editorial judgement; it validates, stores, routes, and measures.
- Shared Knowledge is the only canonical source for common contracts, enums, and cross-product rules.
- SIMS Manager may collect and summarize site-wide performance evidence, but does not make the specialist Algorithm Impact diagnosis.
- aDoctor owns Algorithm Impact interpretation and integrated diagnostic judgement; Google update information remains one Evidence class among others.
- Shared Knowledge defines the cross-product evidence and routing boundary, not aDoctor-specific scoring or causation logic.
